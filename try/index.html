File Formats
  • CSV as in the open dataset: one scan per row; chip, date, subfolder, E_raw_V, I_raw_uA (200 values each, separated by ;). Optional: block_id groups the repeats of a sample; polymer; label_nM_AA, label_nM_5HT, label_nM_2E, label_nM_Mela show as true values.
  • CHI760 text export, square-wave, 0.004 to 0.800 V in 4 mV steps (200 points), current in amperes. Add the blank files measured with the scans, or pick a blank from the library.
  • Files are read in this browser and never uploaded.
