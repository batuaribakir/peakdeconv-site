Stack

What the site is built with

The site

  • Plain HTML, CSS and JavaScript. No build step and no package manager.
  • Classic scripts rather than modules, so the files also open from disk.
  • Relative links throughout, so the same files work at a local server root and under a project path once deployed.

Loaded from the network

  • Google Fonts — Fraunces, Instrument Sans and IBM Plex Mono, on every page.
  • Three.js r134 from cdnjs, on the dashboard only, for its background scene.

Offline, the pages still render on the plain light ground with fallback system fonts; the dashboard simply drops its 3D scene.
